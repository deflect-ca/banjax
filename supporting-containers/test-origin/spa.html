How to test

  1. Open this page at http://localhost/spa (localhost or https, otherwise the browser sends no Sec-Fetch-* headers and nothing is deferred).
  2. Leave polling on. Calls should show OK.
  3. Send a kafka challenge for this site from the repo root: 
    docker compose run --rm kafka-cmd-tester -cmd challenge_all -host localhost
    or for this browser's session only: 
    (loading session id...)
  4. Within the grace period, API calls show PENDING: let through, with X-Banjax-Decision: ShaChallengeDeferred.
  5. Once the grace period is over, they show CHALLENGED (the HTML challenge, 429).
  6. Click Full page load to meet the challenge as a navigation, solve it, and come back: calls are OK again.

Also try adding -score 0.95 (at or above the max score: no grace), a command for a site in attack_mode, or fetch without Referer below (not browser-like: no grace).
